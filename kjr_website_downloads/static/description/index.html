Website-Downloadbereich

Dokumente zentral pflegen und auf der Website anbieten – mit Kategorien, Reihenfolge und Veröffentlichung

Für Dateien ohne feste Rubrik: Positionspapiere, Vorlagen, Merkblätter oder Bausteine eines Schutzkonzepts. Die Redaktion legt Downloads im Backend an, ordnet sie Kategorien zu und schaltet sie frei. Die Website zeigt sie gesammelt auf einer eigenen Seite.

Funktionsumfang

Pflege im Backend

  • Titel, Beschreibung, Datei, Datum und Schalter „Veröffentlicht“
  • Frei pflegbare Kategorien mit eigener Reihenfolge
  • Reihenfolge der Downloads per Ziehen
  • Optional je Website (Multi-Website)
  • Pflege durch die Gruppe Website-Designer

Öffentliche Seite

  • Seite /service/downloads, gruppiert nach Kategorie
  • Dateityp, Größe und Stand je Datei
  • Barrierearm: klare Überschriften, Listen, aussagekräftige Linktexte
  • Im Standard-Layout der Website, Einleitung im Website-Editor befüllbar
  • Auslieferung nur veröffentlichter Dateien

Geprüft & konfigurierbar

Auf Odoo 19 installiert und mit automatisierten Tests abgesichert (Rechte, Veröffentlichung, Gruppierung, Auslieferung). Einen Menüpunkt auf der Website legt das Modul bewusst nicht an; die Menüs pflegt der Betreiber selbst.
